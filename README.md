# Ruang Fikir Sejarah — prototaip

Laman statik untuk GitHub Pages. Buka `index.html` untuk menguji. Fitur: jawapan murid, semakan guru menggunakan pen/stylus, markah, komen, sticky notes, dashboard asas dan eksport demo JSON.

**Penting:** Data hanya localStorage pada satu pelayar/peranti. Tiada autentikasi, role protection atau sync sebenar. Jangan gunakan dengan nama/hasil kerja sebenar murid. Untuk pelaksanaan sekolah: integrasikan Firebase Auth + Firestore Security Rules, ID murid berautentikasi, kawalan guru, semakan realtime, sandaran, dan dasar retensi data.

## Terbitkan
1. Cipta repositori public `teacherziela/ruang-fikir-sejarah`.
2. Upload `index.html` dan `README.md` ke root branch `main`.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Selepas GitHub mengaktifkan Pages, laman biasanya di `https://teacherziela.github.io/ruang-fikir-sejarah/`.

Modul ini berasingan dan tidak mengubah portal HistoryVerse asal.
